# Privacy Policy for AutoFx

Last updated: September 2026

AutoFx ("we", "our", or "the Bot") respects the privacy of its users. This Privacy Policy explains how data is handled when you use AutoFx in your Discord server.

## 1. Information We Process
AutoFx processes messages sent in Discord channels and threads where the bot has read permissions solely to detect Twitter/X links (`twitter.com` and `x.com`).
- **Temporary In-Memory Processing**: The bot inspects message content, author display names, and avatars strictly in volatile memory (RAM) in real time to create the replacement webhook message with fixed embeds.

## 2. Information We Do NOT Collect or Store
- We do **NOT** store, archive, or persist message contents.
- We do **NOT** maintain any database of user messages, server messages, or personal data.
- We do **NOT** track, sell, or share user data with any third parties.
- We do **NOT** use any message data to train machine learning or AI models.

## 3. Data Retention
Because AutoFx does not store message data, there is no message data retention. Once a message is processed (or ignored if no Twitter/X link is present), it is immediately discarded from memory.

## 4. Third-Party Services
To generate working embed previews, the bot rewrites Twitter/X URLs to use third-party redirect services such as FixTweet / FixupX (`fxtwitter.com` / `fixupx.com`). We do not send any user credentials or personal identifying information to these services.

## 5. Opt-Out and Permissions
Server administrators can manage or revoke AutoFx's access to any channel or category at any time using Discord's built-in role and channel permission settings.

## 6. Contact
If you have any questions or concerns regarding this Privacy Policy, please open an issue on our GitHub repository: https://github.com/Yuuzi261/AutoFx
